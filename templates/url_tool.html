URL Analysis

Check URLs and retrieve document details - HTTP status, redirects, file type, page count, size, language and last modified date. Pasted URLs, Excel files and books from the backlog are all analysed by the same engine.

One URL per line. You can also paste rows copied from Excel (Document ID, Book Title, URL...) - columns are detected automatically. Duplicate URLs are analysed once.
An .xlsx or .xls file with one URL per row. All columns are kept in the results.
For pages that show "verifying you are human" (or that the tool cannot read):
  1. Open the page in your normal browser and wait until the real page has loaded.
  2. Press Ctrl+U (view source), then Ctrl+A, Ctrl+C.
    Pages that build their links with JavaScript: press F12 → Console, type copy(document.documentElement.outerHTML) and press Enter (Chrome may ask you to type allow pasting first).
  3. Paste it below (or load a saved .html file), enter the page address, and analyze. The page is not requested again - only the document it links to is.
For one page that lists many PDFs (a code of laws, a list of reports, folders or years you click open...).
  1. Paste the page address.
  2. Scope (optional): a CSS selector for the links you want, e.g. #cmctree>.tlist>li:nth-of-type(1) a[data-pdf*='.pdf']. Leave it empty to take every PDF link on the page.
  3. Collapsed sections inside the scope are opened for you in a browser (only inside the scope), then every PDF found is analysed: page count, last modified, file size, language.
Playwright is not installed, so only the links already in the page's HTML can be read. Run pip install playwright to let the tool open collapsed sections (it uses the Edge or Chrome already on this computer).
With levels, the links the scope above selects are pages to open; on each of those pages the next level's scope selects links, and so on. The links of the last level are the PDFs. Links that only a script knows (javascript:void(0) with a click handler) are clicked in a browser to learn where they lead.
